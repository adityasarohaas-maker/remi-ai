# Memory Companion — Plan 1: Building Blocks + Core Features Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a deployed, judge-usable Memory Companion. It has a family portal, a voice-first tablet app for the patient, and Nemotron agents on Nebius Token Factory. It covers the five must-ship features: "Who is this?", patient answers to repeated questions, family-written answers to painful questions, the daily family digest, and medicine/meal reminders. Safety-word alerts are included.

**Architecture:** One Next.js 16 app. `/family/*` is the family portal (Supabase Auth, RLS-scoped). `/patient/[token]` is the tablet app (device token, no login). `/api/*` routes call Nemotron via the OpenAI-compatible Token Factory API. All product logic lives in pure, unit-tested modules under `src/core/`. Route handlers are thin and inject their IO (Supabase, Nebius, Telegram) through a `deps` object, so the logic can be tested without a network. Face embeddings are computed in the browser with Human (loaded from CDN) and matched on our server. Photos never go to an LLM.

**Tech Stack:** Next.js 16.4.2 (App Router, TypeScript, Tailwind), Supabase (Postgres + Auth + Storage, hosted, region ap-south-1), `openai` 7.x pointed at Nebius Token Factory, `@vladmandic/human` 3.3.6 (browser, CDN), Web Speech API, Telegram Bot API for alerts, Vitest, Vercel (hosting + cron).

**Spec:** `docs/spec/Memory_Companion_Hackathon_Plan.pdf` (project plan). Hackathon rules: https://nebiusglobalaihackathon.devpost.com/rules

## Global Constraints

- Every LLM call goes to Nebius Token Factory, `https://api.tokenfactory.nebius.com/v1/`, via `src/lib/nebius.ts` only.
- Live conversation and recognition use **NVIDIA Nemotron 3.5 Lightning** (env `NEBIUS_CHAT_MODEL`). Digests use **NVIDIA Nemotron 3 Super** `nvidia/nemotron-3-super-120b-a12b` (env `NEBIUS_REPORT_MODEL`). Both are named in the README.
- `NEBIUS_API_KEY`, `SUPABASE_SERVICE_ROLE_KEY`, `TELEGRAM_BOT_TOKEN` and `CRON_SECRET` are server-only. Never prefix them with `NEXT_PUBLIC_`, never commit them, and never ask the user to paste them in chat: the user writes `.env.local` themselves.
- Patient-facing text: short, calm sentences, one idea at a time. Never argue. Never pretend to be a family member. No medical advice or diagnosis.
- Face recognition never guesses. Low confidence or a small margin means "I'm not sure who this is — shall I ask <contact>?".
- The words pain / fell / lost / scared (and their Hindi equivalents) trigger an immediate family alert.
- Face photos and embeddings stay in our Supabase project (private bucket `family-media`). Photos are never sent to any model.
- Fixed patient strings exist in English (`en-IN`) and Hindi (`hi-IN`); any other language falls back to English.
- RLS is enabled on every table. The service-role client is imported only in server code (`import 'server-only'`).
- Submission: public GitHub repo with an MIT `LICENSE` and README setup steps. The hosted demo URL must stay free and unrestricted through judging (Dec 1–15, 2026). Submit on Devpost by **Oct 29, 2026** (hard close Oct 30 10:00 PT).
- Supabase free projects pause after 7 days without activity. The daily cron must touch the DB.
- Dev machine: Windows 11, PowerShell, Node 24.16, npm 11. No Docker, so there is no local Supabase. Work against the hosted project.

## Review Focus

1. **Browser has no SpeechRecognition (Firefox, some iPad Safari):** the Talk screen must show a typed-input box instead of a dead mic button. Pinned in Task 11 (`speechRecognitionCtor` test).
2. **Nebius is down, slow, rate-limited or returns empty text:** the patient still gets a calm fallback sentence, never an error string, and the turn is logged with `fallback: true`. Pinned in Task 5 (`handleTalk` tests).
3. **Public demo abuse (empty, huge or rapid-fire input) burning our Nebius credit:** empty input is rejected, input is capped at 500 chars, and each household gets 20 talk/identify calls per minute. Pinned in Task 5 and Task 6.
4. **Server clock is UTC but the household is in IST:** "What day is it?" at 00:30 IST must say the new day. Pinned in Task 3 (`localParts` test at 2026-10-17T19:00Z).
5. **No face in the frame / camera denied:** the user sees "I can't see a face clearly" (not "I'm not sure who this is") and can choose a photo instead. Pinned in Task 4 (`noFaceMessage`) and Task 11 (photo fallback).

```ts
export function stripReasoning(s: string): string {
  const withoutPairs = s.replace(/<think>[\s\S]*?<\/think>/gi, '');
  const close = withoutPairs.toLowerCase().lastIndexOf('</think>');
  const rest = close >= 0 ? withoutPairs.slice(close + '</think>'.length) : withoutPairs;
  return rest.trim();
}
```

`src/lib/nebius.ts`:
```ts
import 'server-only';
import OpenAI from 'openai';
import { stripReasoning } from '@/core/text';

export type ChatMessage = { role: 'system' | 'user' | 'assistant'; content: string };

export const MODELS = {
  chat: () => process.env.NEBIUS_CHAT_MODEL ?? 'nvidia/Nemotron-3_5-Lightning',
  report: () => process.env.NEBIUS_REPORT_MODEL ?? 'nvidia/nemotron-3-super-120b-a12b',
};

let client: OpenAI | null = null;
function getClient(): OpenAI {
  if (!process.env.NEBIUS_API_KEY) throw new Error('NEBIUS_API_KEY is not set');
  client ??= new OpenAI({
    baseURL: process.env.NEBIUS_BASE_URL ?? 'https://api.tokenfactory.nebius.com/v1/',
    apiKey: process.env.NEBIUS_API_KEY,
    maxRetries: 1,
  });
  return client;
}

export async function chatText(
  messages: ChatMessage[],
  opts: { model: string; maxTokens?: number; temperature?: number; timeoutMs?: number },
): Promise<string> {
  const extra = process.env.NEBIUS_DISABLE_THINKING === '1'
    ? { chat_template_kwargs: { enable_thinking: false } }
    : {};
  const res = await getClient().chat.completions.create(
    {
      model: opts.model,
      messages,
      max_tokens: opts.maxTokens ?? 400,
      temperature: opts.temperature ?? 0.4,
      ...extra,
    } as OpenAI.Chat.ChatCompletionCreateParamsNonStreaming,
    { timeout: opts.timeoutMs ?? 20_000 },
  );
  return stripReasoning(res.choices[0]?.message?.content ?? '');
}
```

```sql
  p_patient_name text, p_preferred_name text, p_language text, p_timezone text
) returns uuid language plpgsql security definer set search_path = '' as $$
declare h uuid; uid uuid := auth.uid();
begin
  if uid is null then raise exception 'not signed in'; end if;
  if exists (select 1 from public.household_members where user_id = uid) then
```

```ts
export type PartOfDay = 'morning' | 'afternoon' | 'evening' | 'night';

function zoned(date: Date, timeZone: string) {
  const parts = new Intl.DateTimeFormat('en-CA', {
    timeZone, year: 'numeric', month: '2-digit', day: '2-digit',
    hour: '2-digit', minute: '2-digit', second: '2-digit', hourCycle: 'h23',
  }).formatToParts(date);
  const get = (t: string) => Number(parts.find((p) => p.type === t)!.value);
  return { y: get('year'), mo: get('month'), d: get('day'), h: get('hour'), mi: get('minute'), s: get('second') };
}

export function partOfDay(hour: number): PartOfDay {
  if (hour < 5) return 'night';
  if (hour < 12) return 'morning';
  if (hour < 17) return 'afternoon';
  if (hour < 21) return 'evening';
  return 'night';
}

export function localParts(date: Date, timeZone: string, locale = 'en-IN') {
  const z = zoned(date, timeZone);
  const pad = (n: number) => String(n).padStart(2, '0');
  return {
    day: `${z.y}-${pad(z.mo)}-${pad(z.d)}`,
    minutes: z.h * 60 + z.mi,
    weekday: new Intl.DateTimeFormat(locale, { timeZone, weekday: 'long' }).format(date),
    prettyDate: new Intl.DateTimeFormat(locale, { timeZone, day: 'numeric', month: 'long', year: 'numeric' }).format(date),
    prettyTime: new Intl.DateTimeFormat(locale, { timeZone, hour: 'numeric', minute: '2-digit' }).format(date),
    partOfDay: partOfDay(z.h),
  };
}

function tzOffsetMinutes(date: Date, timeZone: string): number {
  const z = zoned(date, timeZone);
  return Math.round((Date.UTC(z.y, z.mo - 1, z.d, z.h, z.mi, z.s) - date.getTime()) / 60000);
}

export function dayRangeUtc(day: string, timeZone: string): { start: Date; end: Date } {
  const [y, m, d] = day.split('-').map(Number);
  const at = (dd: number) => {
    const guess = new Date(Date.UTC(y, m - 1, dd));
    return new Date(guess.getTime() - tzOffsetMinutes(guess, timeZone) * 60000);
  };
  return { start: at(d), end: at(d + 1) };
}

export function parseHHMM(t: string): number {
  const [h, m] = t.split(':').map(Number);
  return h * 60 + m;
}
```

```ts
import type { RoutineItem } from './types';
import { parseHHMM } from './time';

export type ReminderState = 'upcoming' | 'due' | 'done' | 'missed';
export type RoutineWithState = RoutineItem & { minutes: number; state: ReminderState };

export function reminderStates(items: RoutineItem[], doneIds: string[], nowMinutes: number, graceMinutes = 60): RoutineWithState[] {
  const done = new Set(doneIds);
  return items
    .map((item) => {
      const minutes = parseHHMM(item.timeOfDay);
      let state: ReminderState;
      if (done.has(item.id)) state = 'done';
      else if (nowMinutes < minutes) state = 'upcoming';
      else if (nowMinutes < minutes + graceMinutes) state = 'due';
      else state = 'missed';
      return { ...item, minutes, state };
    })
    .sort((a, b) => a.minutes - b.minutes);
}
```

```ts
import { stripReasoning } from './text';

export const MOODS = ['calm', 'happy', 'confused', 'anxious', 'sad', 'agitated'] as const;
export type Mood = (typeof MOODS)[number] | 'unknown';

const TAG = /^\s*\[?\s*mood\s*:\s*([a-z]+)\s*\]?\s*$/i;

export function parseMoodTag(raw: string): { reply: string; mood: Mood } {
  let mood: Mood = 'unknown';
  const kept: string[] = [];
  for (const line of stripReasoning(raw).split('\n')) {
    const m = line.match(TAG);
    if (m) {
      const word = m[1].toLowerCase();
      mood = (MOODS as readonly string[]).includes(word) ? (word as Mood) : 'unknown';
    } else kept.push(line);
  }
  return { reply: kept.join('\n').trim(), mood };
}
```

```ts
import type { Guidance, Person } from './types';
import type { RoutineWithState } from './reminders';
import type { PartOfDay } from './time';
import type { SafetyCategory } from './safety';
import type { ChatMessage } from '@/lib/nebius';

const LANGUAGE_NAMES: Record<string, string> = { en: 'English', hi: 'Hindi', ta: 'Tamil', te: 'Telugu', bn: 'Bengali', mr: 'Marathi', gu: 'Gujarati', pa: 'Punjabi', kn: 'Kannada', ml: 'Malayalam' };
export const languageName = (code: string) => LANGUAGE_NAMES[code.split('-')[0].toLowerCase()] ?? 'English';

const STATE_TEXT = { upcoming: 'later today', due: 'due now', done: 'done', missed: 'not done yet' } as const;

function clock(minutes: number): string {
  const h = Math.floor(minutes / 60); const m = minutes % 60;
  const h12 = h % 12 === 0 ? 12 : h % 12;
  return `${h12}:${String(m).padStart(2, '0')} ${h < 12 ? 'am' : 'pm'}`;
}

export interface CompanionPromptInput {
  preferredName: string; language: string; about: string | null;
  now: { weekday: string; prettyDate: string; prettyTime: string; partOfDay: PartOfDay };
  people: Person[]; routine: RoutineWithState[]; primaryContactName: string | null;
  sensitive: Guidance | null; safety: SafetyCategory[];
}

const APPROACH: Record<Guidance['approach'], (who: string, call: string) => string> = {
  redirect: (who) => `Gently move ${who}'s attention to something comforting happening now. Do not discuss where this person is.`,
  share_memory: (who) => `Share the family's happy memory with ${who} warmly, then stay with that good feeling.`,
  call_relative: (who, call) => `Tell ${who} kindly that you are asking ${call} to call them right now, and offer the family's words.`,
};

export function buildCompanionPrompt(i: CompanionPromptInput): string {
  const who = i.preferredName;
  const contact = i.primaryContactName ?? 'the family';
  const people = i.people.length
    ? i.people.map((p) => `- ${p.name} — ${p.relation}${p.isDeceased ? ' (has passed away — if asked about them, follow the family guidance; never say they are coming)' : ''}${p.notes ? `. ${p.notes}` : ''}`).join('\n')
    : '- (none written yet)';
  const routine = i.routine.length
    ? i.routine.map((r) => `- ${clock(r.minutes)} ${r.label} — ${STATE_TEXT[r.state]}`).join('\n')
    : '- (no routine written yet)';

  const sections = [
    `You are a gentle companion on a tablet for ${who}, who lives with dementia. You talk to ${who} directly.`,
    `How you speak:
- Short, calm sentences. One idea at a time. At most 3 sentences.
- Reply in ${languageName(i.language)}, with simple everyday words.
- Answer repeated questions as warmly as the first time. Never say "you already asked" or "as I said".
- Never argue or harshly correct ${who}. If something is not accurate, respond to the feeling and steer gently to something pleasant.
- Never pretend to be a family member or any real person. You are the companion.
- Never give medical advice or a diagnosis. For health worries, say you will tell ${contact}.
- Only use the facts below. If you do not know, say so kindly and offer to ask ${contact}.`,
    `Right now: ${i.now.weekday}, ${i.now.prettyDate}, ${i.now.prettyTime} (${i.now.partOfDay}).`,
    `About ${who}: ${i.about ?? '(not written yet)'}`,
    `Family and friends:\n${people}`,
    `Today's routine:\n${routine}`,
  ];

  if (i.sensitive) {
    sections.push(`IMPORTANT — the family wrote how to handle this topic ("${i.sensitive.topic}"):
${APPROACH[i.sensitive.approach](who, i.sensitive.callPersonName ?? contact)}
The family's words: "${i.sensitive.familyScript}"
Follow the family's guidance closely. Do not say that anyone has died unless the family's words say so.`);
  }
  if (i.safety.length) {
    sections.push(`${who} may be in difficulty (${i.safety.join(', ')}). Reassure them calmly and tell them you are letting ${contact} know right now. Do not promise anything else.`);
  }
  sections.push(`At the very end, on its own line, write MOOD: and one word for how ${who} seems — calm, happy, confused, anxious, sad or agitated. ${who} will not see this line.`);
  return sections.join('\n\n');
}
```

```ts
import type { HouseholdContext } from './types';
import type { ChatMessage } from '@/lib/nebius';
import type { AlertReason } from '@/lib/alerts';
import type { FaceSample } from './face-match';
import { localParts } from './time';
import { reminderStates } from './reminders';
import { detectSafetyWords } from './safety';
import { findSensitiveGuidance } from './sensitive';
import { parseMoodTag, type Mood } from './mood';
import { buildCompanionPrompt } from './companion-prompt';
import { fallbackReply } from './messages';

export const MAX_INPUT = 500;
export const RATE_PER_MIN = 20;

export interface CoreDeps {
  now(): Date;
  loadContext(householdId: string, now: Date): Promise<HouseholdContext>;
  recentTurns(householdId: string, since: Date): Promise<{ text: string; reply: string }[]>;
  countRecentEvents(householdId: string, type: string, since: Date): Promise<number>;
  chat(messages: ChatMessage[], opts: { maxTokens: number; temperature: number }): Promise<string>;
  logEvent(householdId: string, type: string, payload: Record<string, unknown>): Promise<void>;
  alert(householdId: string, reason: AlertReason, detail: string): Promise<void>;
  faceGallery(householdId: string): Promise<FaceSample[]>;
}

export async function handleTalk(deps: CoreDeps, input: { householdId: string; text: string }) {
  const text = input.text.trim().slice(0, MAX_INPUT);
  if (!text) return { status: 400, body: { error: 'empty' } };
  const now = deps.now();
  const { householdId } = input;
  if ((await deps.countRecentEvents(householdId, 'conversation', new Date(now.getTime() - 60_000))) >= RATE_PER_MIN) {
    return { status: 429, body: { error: 'too many requests' } };
  }

  const ctx = await deps.loadContext(householdId, now);
  const h = ctx.household;
  const local = localParts(now, h.timezone);
  const safety = detectSafetyWords(text);
  const sensitive = findSensitiveGuidance(text, ctx.guidance);

  const alerts: Promise<void>[] = [];
  if (safety.length) alerts.push(deps.alert(householdId, 'safety', `${h.preferredName} said: "${text}" (${safety.join(', ')})`));
  if (sensitive?.approach === 'call_relative') {
    alerts.push(deps.alert(householdId, 'call_request', `${h.preferredName} is asking about ${sensitive.topic}. Please call ${sensitive.callPersonName ?? h.primaryContactName ?? 'her'} now.`));
  }

  const system = buildCompanionPrompt({
    preferredName: h.preferredName, language: h.language, about: h.about,
    now: local, people: ctx.people,
    routine: reminderStates(ctx.routine, ctx.doneIds, local.minutes),
    primaryContactName: h.primaryContactName, sensitive, safety,
  });
  const history = (await deps.recentTurns(householdId, new Date(now.getTime() - 30 * 60_000))).slice(-6);
  const messages: ChatMessage[] = [
    { role: 'system', content: system },
    ...history.flatMap((t): ChatMessage[] => [{ role: 'user', content: t.text }, { role: 'assistant', content: t.reply }]),
    { role: 'user', content: text },
  ];

  let reply = '';
  let mood: Mood = 'unknown';
  let fallback = false;
  try {
    ({ reply, mood } = parseMoodTag(await deps.chat(messages, { maxTokens: 300, temperature: 0.4 })));
    if (!reply) throw new Error('empty reply');
  } catch {
    reply = fallbackReply(h.language);
    fallback = true;
  }

  await Promise.allSettled(alerts);
  await deps.logEvent(householdId, 'conversation', { text, reply, mood, safety, sensitiveTopic: sensitive?.topic ?? null, fallback });
  return { status: 200, body: { reply, mood, alerted: alerts.length > 0 } };
}
```

```ts
import { supabaseAdmin } from '@/lib/supabase/server';
import { chatText, MODELS } from '@/lib/nebius';

import { localParts, dayRangeUtc } from '@/core/time';
import type { CoreDeps } from '@/core/talk';
import type { HouseholdContext } from '@/core/types';

export function supabaseDeps(): CoreDeps {
  const db = supabaseAdmin();
  return {
    now: () => new Date(),

    async loadContext(householdId, now): Promise<HouseholdContext> {
      const [h, people, routine, guidance] = await Promise.all([
        db.from('households').select('*').eq('id', householdId).single(),
        db.from('people').select('id, name, relation, notes, is_deceased').eq('household_id', householdId).order('created_at'),
        db.from('routine_items').select('id, time_of_day, kind, label, spoken_message').eq('household_id', householdId).eq('active', true),
        db.from('sensitive_guidance').select('id, topic, trigger_words, approach, family_script, caller:people(name)').eq('household_id', householdId),
      ]);
      if (h.error) throw h.error;
      const tz = h.data.timezone as string;
      const { start, end } = dayRangeUtc(localParts(now, tz).day, tz);
      const done = await db.from('events').select('payload').eq('household_id', householdId).eq('type', 'reminder_done')
        .gte('created_at', start.toISOString()).lt('created_at', end.toISOString());
      return {
        household: {
          id: h.data.id, patientName: h.data.patient_name, preferredName: h.data.preferred_name,
          language: h.data.language, timezone: tz, about: h.data.about, homeAddress: h.data.home_address,
          primaryContactName: h.data.primary_contact_name, primaryContactPhone: h.data.primary_contact_phone,
        },
        people: (people.data ?? []).map((p) => ({ id: p.id, name: p.name, relation: p.relation, notes: p.notes, isDeceased: p.is_deceased })),
        routine: (routine.data ?? []).map((r) => ({ id: r.id, timeOfDay: r.time_of_day, kind: r.kind, label: r.label, spokenMessage: r.spoken_message })),
        doneIds: (done.data ?? []).map((e) => (e.payload as { routineItemId: string }).routineItemId),
        guidance: (guidance.data ?? []).map((g) => ({
          id: g.id, topic: g.topic, triggerWords: g.trigger_words, approach: g.approach, familyScript: g.family_script,
          callPersonName: (g.caller as unknown as { name: string } | null)?.name ?? null,
        })),
      };
    },

    async recentTurns(householdId, since) {
      const { data } = await db.from('events').select('payload').eq('household_id', householdId).eq('type', 'conversation')
        .gte('created_at', since.toISOString()).order('created_at', { ascending: true }).limit(20);
      return (data ?? []).map((e) => e.payload as { text: string; reply: string });
    },

    async countRecentEvents(householdId, type, since) {
      const { count } = await db.from('events').select('id', { count: 'exact', head: true })
        .eq('household_id', householdId).eq('type', type).gte('created_at', since.toISOString());
      return count ?? 0;

    chat: (messages, opts) => chatText(messages, { model: MODELS.chat(), ...opts }),

    async logEvent(householdId, type, payload) {
      const { error } = await db.from('events').insert({ household_id: householdId, type, payload });

    alert: sendAlert,

    async faceGallery(householdId) {
      const { data } = await db.from('face_embeddings').select('person_id, embedding').eq('household_id', householdId);
      return (data ?? []).map((r) => ({ personId: r.person_id, embedding: r.embedding as number[] }));
    },
  };
```

```ts
export const EMBEDDING_LENGTH = 1024;
export interface FaceSample { personId: string; embedding: number[] }
export interface MatchOptions { minScore: number; minMargin: number }
export const DEFAULT_MATCH: MatchOptions = { minScore: 0.6, minMargin: 0.06 };

export type MatchResult =
  | { status: 'match'; personId: string; score: number }
  | { status: 'unsure'; bestScore: number }
  | { status: 'no_faces_enrolled' };

export function cosine(a: number[], b: number[]): number {
  if (a.length !== b.length || a.length === 0) return 0;
  let dot = 0, na = 0, nb = 0;
  for (let i = 0; i < a.length; i++) { dot += a[i] * b[i]; na += a[i] * a[i]; nb += b[i] * b[i]; }
  return na && nb ? dot / Math.sqrt(na * nb) : 0;
}

export function isValidEmbedding(x: unknown): x is number[] {
  return Array.isArray(x) && x.length === EMBEDDING_LENGTH && x.every((n) => typeof n === 'number' && Number.isFinite(n) && Math.abs(n) <= 10);
}

export function matchFace(probe: number[], gallery: FaceSample[], opts: MatchOptions = DEFAULT_MATCH): MatchResult {
  if (!gallery.length) return { status: 'no_faces_enrolled' };
  const best = new Map<string, number>();
  for (const s of gallery) best.set(s.personId, Math.max(best.get(s.personId) ?? -1, cosine(probe, s.embedding)));
  const ranked = [...best.entries()].sort((a, b) => b[1] - a[1]);
  const [topId, topScore] = ranked[0];
  const second = ranked[1]?.[1] ?? -1;
  if (topScore >= opts.minScore && topScore - second >= opts.minMargin) return { status: 'match', personId: topId, score: topScore };
  return { status: 'unsure', bestScore: topScore };
}
```

`src/core/identify.ts`:
```ts
import type { CoreDeps } from './talk';
import { RATE_PER_MIN } from './talk';
import { DEFAULT_MATCH, isValidEmbedding, matchFace } from './face-match';
import { buildRecognitionMessages } from './companion-prompt';
import { parseMoodTag } from './mood';
import { simpleRecognition, unsureMessage } from './messages';

export async function handleIdentify(deps: CoreDeps, input: { householdId: string; embedding: unknown }) {
  if (!isValidEmbedding(input.embedding)) return { status: 400, body: { error: 'bad embedding' } };
  const { householdId, embedding } = input;
  const now = deps.now();
  if ((await deps.countRecentEvents(householdId, 'face_query', new Date(now.getTime() - 60_000))) >= RATE_PER_MIN) {
    return { status: 429, body: { error: 'too many requests' } };
  }
  const [ctx, gallery] = await Promise.all([deps.loadContext(householdId, now), deps.faceGallery(householdId)]);
  const h = ctx.household;
  const result = matchFace(embedding, gallery, DEFAULT_MATCH);
  const person = result.status === 'match' ? ctx.people.find((p) => p.id === result.personId) : undefined;

  if (result.status !== 'match' || !person) {
    const reply = unsureMessage(h.language, h.primaryContactName);
    await deps.logEvent(householdId, 'face_query', { status: 'unsure', score: result.status === 'unsure' ? result.bestScore : null });
    return { status: 200, body: { status: 'unsure', reply } };
  }

  let reply: string;
  try {
    reply = parseMoodTag(await deps.chat(buildRecognitionMessages({ preferredName: h.preferredName, language: h.language, person }), { maxTokens: 120, temperature: 0.4 })).reply;
    if (!reply) throw new Error('empty');
  } catch {
    reply = simpleRecognition(h.language, person.name, person.relation);
  }
  await deps.logEvent(householdId, 'face_query', { status: 'match', personId: person.id, name: person.name, score: result.score });
  return { status: 200, body: { status: 'match', name: person.name, relation: person.relation, reply } };
}
```

```ts
import type { Human, Config } from '@vladmandic/human';

const HUMAN_URL = 'https://cdn.jsdelivr.net/npm/@vladmandic/human@3.3.6/dist/human.esm.js';
const MODELS_URL = 'https://cdn.jsdelivr.net/npm/@vladmandic/human@3.3.6/models/';

let humanPromise: Promise<Human> | null = null;

export function loadHuman(): Promise<Human> {
  humanPromise ??= (async () => {
    const mod = await import(/* webpackIgnore: true */ /* turbopackIgnore: true */ HUMAN_URL);
    const HumanCtor = (mod.Human ?? mod.default) as new (c: Partial<Config>) => Human;
    const human = new HumanCtor({
      modelBasePath: MODELS_URL,
      debug: false,
      face: {
        enabled: true,
        detector: { enabled: true, maxDetected: 3, rotation: false },
        mesh: { enabled: true }, description: { enabled: true },
        iris: { enabled: false }, emotion: { enabled: false }, antispoof: { enabled: false }, liveness: { enabled: false },
      },
      body: { enabled: false }, hand: { enabled: false }, object: { enabled: false },
      gesture: { enabled: false }, segmentation: { enabled: false },
    } as Partial<Config>);
    await human.load();
    await human.warmup();
    return human;
  })();
  return humanPromise;

export async function embedFrom(input: HTMLImageElement | HTMLVideoElement | HTMLCanvasElement): Promise<number[] | null> {
  const human = await loadHuman();
  const res = await human.detect(input);
  const faces = res.face
    .filter((f) => (f.embedding?.length ?? 0) > 0 && (f.faceScore ?? f.score ?? 0) > 0.6)
    .sort((a, b) => b.box[2] * b.box[3] - a.box[2] * a.box[3]);
  return faces[0]?.embedding ? Array.from(faces[0].embedding) : null;
}

export function fileToImage(file: File): Promise<HTMLImageElement> {
  return new Promise((resolve, reject) => {
    const img = new Image();
    img.onload = () => resolve(img);
    img.onerror = () => reject(new Error('Could not read that image'));
    img.src = URL.createObjectURL(file);
  });
}
```

```ts
export interface SpeechRecognitionLike {
  lang: string; interimResults: boolean; maxAlternatives: number;
  onresult: ((e: { results: ArrayLike<ArrayLike<{ transcript: string }>> }) => void) | null;
  onerror: ((e: { error: string }) => void) | null;
  onend: (() => void) | null;
  start(): void; stop(): void;
}

export function speechRecognitionCtor(win: unknown): (new () => SpeechRecognitionLike) | null {
  const w = win as { SpeechRecognition?: unknown; webkitSpeechRecognition?: unknown } | undefined;
  return ((w?.SpeechRecognition ?? w?.webkitSpeechRecognition) as (new () => SpeechRecognitionLike) | undefined) ?? null;
}

export function speak(text: string, lang: string): void {
  if (typeof window === 'undefined' || !('speechSynthesis' in window)) return;
  const synth = window.speechSynthesis;
  synth.cancel();
  const u = new SpeechSynthesisUtterance(text);
  u.lang = lang; u.rate = 0.9;
  const voices = synth.getVoices();
  u.voice = voices.find((v) => v.lang === lang) ?? voices.find((v) => v.lang.startsWith(lang.split('-')[0])) ?? null;
  synth.speak(u);
}

export function listenOnce(lang: string): Promise<string> {
  return new Promise((resolve, reject) => {
    const Ctor = speechRecognitionCtor(typeof window === 'undefined' ? undefined : window);
    if (!Ctor) return reject(new Error('unsupported'));
    const rec = new Ctor();
    rec.lang = lang; rec.interimResults = false; rec.maxAlternatives = 1;
    let heard = '';
    rec.onresult = (e) => { heard = e.results[0]?.[0]?.transcript ?? ''; };
    rec.onerror = (e) => reject(new Error(e.error));
    rec.onend = () => resolve(heard.trim());
    rec.start();
  });
}
```

```ts
import { localParts, type PartOfDay } from './time';
import type { RoutineWithState, ReminderState } from './reminders';
import type { Mood } from './mood';

export interface DayEvent { type: string; payload: Record<string, unknown>; created_at: string }
export interface DayFacts {
  day: string;
  conversations: number;
  fallbacks: number;
  moodCounts: Partial<Record<Mood, number>>;
  moodByPart: Partial<Record<PartOfDay, Mood>>;
  topQuestions: { text: string; count: number }[];
  sensitiveTopics: { topic: string; count: number }[];
  reminders: { time: string; label: string; kind: string; state: ReminderState }[];
  missedMedicines: string[];
  alerts: { time: string; reason: string; detail: string }[];
  recognized: { name: string; count: number }[];
  unsureFaces: number;
}

// (?=\s|$) instead of \b: JS \b does not treat Devanagari as word characters
const QUESTION_START = /^(what|when|where|who|why|how|is|are|am|can|will|did|do|does|kya|kab|kahan|kaun|kyun|kaise|क्या|कब|कहाँ|कौन|क्यों|कैसे)(?=\s|$)/i;
const norm = (s: string) => s.toLowerCase().replace(/[^\p{L}\p{M}\p{N}\s]/gu, ' ').replace(/\s+/g, ' ').trim();
const isQuestion = (s: string) => /[?？]\s*$/.test(s) || QUESTION_START.test(s.trim());

function tally(keys: string[]): { key: string; count: number }[] {
  const m = new Map<string, number>();
  for (const k of keys) m.set(k, (m.get(k) ?? 0) + 1);
  return [...m.entries()].map(([key, count]) => ({ key, count })).sort((a, b) => b.count - a.count);
}

export function summarizeDay(day: string, events: DayEvent[], reminders: RoutineWithState[], timeZone: string): DayFacts {
  const convo = events.filter((e) => e.type === 'conversation');
  const moodCounts: Partial<Record<Mood, number>> = {};
  const byPart: Partial<Record<PartOfDay, Mood[]>> = {};
  for (const e of convo) {
    const mood = (e.payload.mood as Mood) ?? 'unknown';
    if (mood === 'unknown') continue;
    moodCounts[mood] = (moodCounts[mood] ?? 0) + 1;
    const part = localParts(new Date(e.created_at), timeZone).partOfDay;
    (byPart[part] ??= []).push(mood);
  }
  const moodByPart: Partial<Record<PartOfDay, Mood>> = {};
  for (const [part, moods] of Object.entries(byPart) as [PartOfDay, Mood[]][]) moodByPart[part] = tally(moods)[0].key as Mood;

  const faces = events.filter((e) => e.type === 'face_query');
  return {
    day,
    conversations: convo.length,
    fallbacks: convo.filter((e) => e.payload.fallback === true).length,
    moodCounts,
    moodByPart,
    topQuestions: tally(convo.map((e) => String(e.payload.text ?? '')).filter(isQuestion).map(norm))
      .slice(0, 5).map(({ key, count }) => ({ text: key, count })),
    sensitiveTopics: tally(convo.map((e) => e.payload.sensitiveTopic).filter((t): t is string => typeof t === 'string'))
      .map(({ key, count }) => ({ topic: key, count })),
    reminders: reminders.map((r) => ({ time: r.timeOfDay.slice(0, 5), label: r.label, kind: r.kind, state: r.state })),
    missedMedicines: reminders.filter((r) => r.kind === 'medicine' && r.state === 'missed').map((r) => r.label),
    alerts: events.filter((e) => e.type === 'alert').map((e) => ({
      time: localParts(new Date(e.created_at), timeZone).prettyTime,
      reason: String(e.payload.reason ?? ''), detail: String(e.payload.detail ?? ''),
    })),
    recognized: tally(faces.filter((e) => e.payload.status === 'match').map((e) => String(e.payload.name)))
      .map(({ key, count }) => ({ name: key, count })),
    unsureFaces: faces.filter((e) => e.payload.status === 'unsure').length,
  };
}
```

```ts
import 'server-only';
import { supabaseAdmin } from '@/lib/supabase/server';
import { chatText, MODELS } from '@/lib/nebius';
import { supabaseDeps } from '@/lib/deps';
import { localParts, dayRangeUtc } from '@/core/time';
import { reminderStates } from '@/core/reminders';
import { summarizeDay, type DayEvent } from '@/core/day-summary';
import { buildDigestMessages } from '@/core/digest-prompt';

export async function generateDigest(householdId: string, dayArg?: string) {
  const db = supabaseAdmin();
  const now = new Date();
  const ctx = await supabaseDeps().loadContext(householdId, now);
  const tz = ctx.household.timezone;
  const local = localParts(now, tz);
  const day = dayArg ?? local.day;
  const { start, end } = dayRangeUtc(day, tz);
  const { data: events } = await db.from('events').select('type, payload, created_at')
    .eq('household_id', householdId).gte('created_at', start.toISOString()).lt('created_at', end.toISOString())
    .order('created_at').limit(2000);
  const minutes = day === local.day ? local.minutes : 24 * 60;
  const facts = summarizeDay(day, (events ?? []) as DayEvent[], reminderStates(ctx.routine, ctx.doneIds, minutes), tz);
  const summary = await chatText(buildDigestMessages(ctx.household.preferredName, facts), { model: MODELS.report(), maxTokens: 700, temperature: 0.3, timeoutMs: 60_000 });
  await db.from('digests').upsert({ household_id: householdId, day, facts, summary, model: MODELS.report() }, { onConflict: 'household_id,day' });
  return { day, summary, facts };
}
```
